# 📊 Sales Performance Dashboard

An end-to-end Data Analytics project that analyzes retail sales data using **Excel, SQL, Python, and Tableau** to uncover business insights and build an interactive dashboard.

---

## 🎯 Business Objective

The objective of this project is to analyze historical sales data, identify sales and profit trends, evaluate regional and product performance, 
and generate actionable business insights through data analysis and visualization.

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- MySQL
- Python (Pandas, NumPy, Matplotlib)
- Tableau
